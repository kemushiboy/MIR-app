# MIR-app デザイン・実装ガイド

タブ (ワークスペース) を追加するときに、見た目と動作の重さをアプリ全体でそろえるためのルールです。

## 1. デザインの原則

| 原則 | このアプリでのルール |
|---|---|
| **近接** | 関係するものを近づけ、関係しないものは離す。ラベルと入力欄は 4px、フィールド同士は 12px、セクション同士は区切り線 + 16px。操作ボタンは、操作する対象のそば (例: 元に戻すはキャンバスのツールバー、ファイル操作はプロジェクト名の隣) に置く。 |
| **整列** | 3 列 (左パネル・ステージ・右パネル) の上端の帯をすべて高さ `--bar-h` (44px) にそろえる。パネル内は左揃え。入力欄は `grid2` / `grid3` / `grid4` で列をそろえる。同じ種類のボタンは同じ揃え (プリセットは左揃え)。 |
| **コントラスト** | 文字は 3 段階: 見出し (13px 太字・明るい) / 本文 (13px) / 補助 (12・11px・暗め)。**主要操作 (`.primary`) は 1 画面に 1 つだけ**。削除などは普段は控えめにし、ホバーで赤く示す。重要な数値は `.metric` で大きく表示する。 |
| **反復** | 色・余白・文字サイズ・高さ・角丸は `style.css` の `:root` のトークンだけを使う (直接 px や色を書かない)。同じ役割には同じ部品を使う。 |

## 2. デザイントークン (`src/renderer/style.css` の `:root`)

| 種類 | トークン |
|---|---|
| 面の色 | `--bg` / `--surface` (パネル) / `--surface-2` (カード・ボタン) / `--surface-3` (ホバー・選択) / `--sunken` (入力欄・ステージ) |
| 線 | `--line` / `--line-strong` |
| 文字色 | `--text` (本文) / `--text-2` (やや弱い) / `--muted` (補助) |
| 意味の色 | `--accent` 系 (主要操作・選択) / `--danger` 系 / `--warn` 系 / `--ok-text` / `--info` 系 / `--guide` (ガイド線) |
| 余白 | `--sp-1` 4 / `--sp-2` 8 / `--sp-3` 12 / `--sp-4` 16 / `--sp-5` 24 (px) |
| 文字 | `--fs-xs` 11 / `--fs-sm` 12 / `--fs-md` 13 / `--fs-lg` 15 / `--fs-xl` 20 (数値表示) |
| 高さ | `--h-sm` 26 (小ボタン・トグル) / `--h-md` 30 (標準) / `--h-lg` 40 (主要操作) / `--bar-h` 44 (帯) |
| 角丸 | `--r-sm` 4 / `--r-md` 6 / `--r-lg` 10 |

canvas に描く色も、可能な限り `cssVar('--text')` のようにトークンから取得します。

## 3. 部品

| 用途 | クラス |
|---|---|
| ボタン | `button` (標準) / `.primary` (主要操作、1 画面 1 つ) / `.danger` (削除) / `.ghost` (枠なし) / `.small` / `.icon` / `.block` / `.lg` |
| 表示の切り替え (オン・オフ) | `<label class="chip"><input type="checkbox"> 名前</label>` |
| 択一の切り替え | `<div class="seg"><button data-v="…" class="active">…</button>…</div>` (`.seg.block` で全幅) |
| フィールド | `<label>名前 <span class="unit">m</span><input></label>` (単位は名前の横、入力欄は次の行) |
| お知らせ | `.note.info` / `.note.warn` / `.note.err` |
| 重要な数値 | `.metrics > .metric > .v (値 + <small>単位</small>) + .k (名前)` |
| 一覧の行 | 左に色見本 `.swatch`、選択中は `--accent-soft` の背景 + `--accent-strong` の枠 |

## 4. 画面の骨格 (全タブ共通)

```
┌ アプリバー: ロゴ │ タブ │ … │ プロジェクト名 新規 開く 保存 │ FFmpeg ┐
├ 左パネル ──────┬ ツールバー (.ws-toolbar) ─────┬ 右パネル ──────┤ ← 高さ --bar-h でそろえる
│ .panel-head    │ 表示切替 │ 情報 … トグル │ 操作│ .panel-head/.tabs│
│ .panel-body    │ ステージ (.stage)               │ .panel-body      │
│  section …     │ 下部バー (.ws-footer)           │  section …       │
└ ステータスバー (左: メッセージ / 右: 表示中のタブの情報) ───────────┘
```

- 左パネル = 入力素材・前提条件、中央 = 結果の表示と直接操作、右パネル = 選択中のものの詳細設定。
- ツールバーは「表示の切り替え → 情報 → (余白) → 表示オプションのトグル → 操作ボタン」の順に並べ、グループの間は `.divider` で区切る。
- 操作のヒントはステージ下中央の `.stage-hint` に 1 行で書く。

## 5. 動作の軽さ (タブのライフサイクル)

タブは `src/renderer/shell.js` の `App` が管理します。**表示していないタブは何も処理しない** のがルールです。

| フック | 呼ばれるとき | やること |
|---|---|---|
| `scripts` (登録時に指定) | 初めて開いたとき | スクリプトを遅延読み込みする (起動時には読み込まない) |
| `init()` | 初めて開いたとき 1 回 | イベント登録・WebGL などの重い初期化 |
| `show()` | 表示されるたび | 最新の状態を取り込み、描画を再開する |
| `hide()` | 非表示になるたび | **描画ループ・動画再生・タイマー・キー入力の状態をすべて止める** |
| `getState()` / `setState()` / `reset()` | 保存・読み込み・新規 | プロジェクトファイルに入れる設定。未表示のタブには、初めて開いたときに渡される |
| `onDropFiles(paths)` | ファイルがドロップされたとき | 表示中のタブだけが受け取る |

描画のルール:

- `requestAnimationFrame` を回し続けない。状態が変わったときに `invalidate()` で 1 回だけ描く。
- 連続描画は「キーを押して移動している間」「動画の再生中」など、変化が続く間だけにする。
- キーボードショートカットは `App.isActive('自分のタブ')` のときだけ処理する。
- ステータスバー右側は表示中のタブが書く。`hide()` で消す。

## 6. 新しいタブを追加する手順

1. `index.html`
   - アプリバーの `.ws-tabs` にボタン `<button class="ws-tab" data-ws="xxx">名前</button>` を追加
   - `<main class="workspace" data-ws="xxx" hidden>` を 4 章の骨格で追加
2. `src/renderer/xxx.js` を作り、`window.XxxWorkspace = { init, show, hide, getState, setState, reset }` を公開
3. `src/renderer/workspaces.js` に登録
   ```js
   App.register({ id: 'xxx', scripts: ['xxx.js'], module: () => window.XxxWorkspace });
   ```
4. スタイルは `style.css` の末尾に「xxx タブ」セクションを作り、トークンだけを使って書く
5. 確認: 主要操作は 1 つか / 3 列の上端がそろっているか / 非表示にしたとき CPU 使用率が下がるか
